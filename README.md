# Material Natura — Vibe Coding

Materiais de aula e arquivos de referência para desenvolvimento de interfaces com IA. O conteúdo reúne apresentações, regras de projeto, prompts de sistema, design system e um roteiro de conversão de layouts do Figma para React.

## Arquivos

- `Vibe Coding Aula 01 - Prof. Lucas Sousa.pdf`: apresentação da primeira aula.
- `Vibe Coding Aula 02 - Prof. Lucas Sousa.pdf`: apresentação da segunda aula.
- `design-system.md`: prompt e tokens semânticos para documentar um design system.
- `figma-to-react.md`: regras para converter referências do Figma em React.
- `natura-product-dev.rules.md`: regras de desenvolvimento do produto.
- `system-prompts.md`: prompts de sistema para apoiar o fluxo de criação.

## Stack adotada nos materiais

- React 19+
- TypeScript em modo estrito
- Tailwind CSS v4
- Base UI React
- Tailwind Variants e Tailwind Merge
- Lucide React ou Phosphor Icons

## Como usar

1. Comece pelos PDFs para acompanhar o contexto das aulas.
2. Use `design-system.md` para definir tokens e componentes antes da implementação.
3. Use `figma-to-react.md` ao transformar um frame ou screenshot em componentes.
4. Combine as regras do projeto com os prompts apenas depois de revisar o contexto e as restrições da atividade.

Este repositório é uma coleção de materiais; não há aplicação para instalar ou executar.
